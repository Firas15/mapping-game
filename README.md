# Mapping

Пошаговая стратегия в браузере: выберите страну и объедините Европу — от Португалии до Урала.
Упрощённая HOI4: несколько ресурсов, понятные решения, особенности у каждой страны.

## Как играть

- **Цель:** захватить или мирно присоединить все 41 страну.
- **Ресурсы:** деньги, армия, стабильность (умножает доход), влияние (мирное присоединение).
- **Ход = сезон.** Зимой у некоторых стран бонус к обороне.
- **Война:** атаковать можно соседей по суше и по морским путям (пунктир). 2 атаки за ход. Вся армия страны защищает все её земли, на родной земле +40% к обороне.
- **Соседи:** компьютерные страны копят армию и воюют. Националисты агрессивнее, демократы осторожнее. С 6-го хода могут напасть на вас.
- **Решения:** каждый ход выпадают 3 карточки, принять можно одну.
- **Дипломатия:** улучшайте отношения за влияние, от +50 можно заключить союз. Союзники не нападают, помогают в боях у своих границ и присоединяются мирно за полцены.
- **Улучшения:** 12 технологий за деньги в четырёх ветках: экономика, армия, оборона, дипломатия.
- **Политика:** у каждой страны 4 партии. Правящая партия даёт бонус, выборы раз в 8 ходов.
- **События:** кризисы, находки, протесты и революции. Выберите один из двух вариантов, последствия видны заранее. Ниже 20% стабильности грозит революция.

## Разработка

```bash
npm install
npm run dev
```

- `npm run build` — сборка в `dist/`
- `npm run build:map` — пересобрать карту `src/data/europe.json` из Natural Earth (world-atlas)
- `npm run build:flags` — скопировать флаги в `public/flags`

Стек: TypeScript, Vite, d3-geo, d3-zoom, topojson. Карта — Natural Earth 1:50m, флаги — [flag-icons](https://github.com/lipis/flag-icons) (MIT), иконки — [Lucide](https://lucide.dev).
