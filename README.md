# Mapping

Пошаговая стратегия в браузере: выберите страну и объедините Европу — от Португалии до Урала.
Упрощённая HOI4: армии, флоты и авиация на карте, войны и мир, политика, но правила понятны с ходу.

**Играть:** https://firas15.github.io/mapping-game/

## Как играть

- **Цель:** вся Европа — 41 страна, 202 области. Или короткая партия на 30 ходов: побеждает самая большая держава.
- **Сложность:** лёгкая, обычная, тяжёлая — влияет на силу и агрессию компьютерных стран.
- **Ресурсы:** деньги, армия, стабильность (доход и восстания), влияние (отношения, союзы, мирное присоединение).
- **Морские переправы** соединяют близкие берега одного моря: на острова (Корсика, Сардиния, Балеары, Крит, датские острова) можно высадиться.
- **Отношения** на старте — как в нынешней Европе: союзы ЕС и НАТО, Россия и Беларусь, старые споры.
- **Войска** — фишки на карте:
  - **армии** ходят по своим областям и атакуют соседние; все ваши армии рядом с целью атакуют вместе;
  - **флоты** стоят в морях: пока ваш флот сильнее, враг не высадится через это море, и наоборот;
  - **авиация** бьёт по вражеским армиям и флотам в двух областях от базы, но землю не берёт.
- **Война и мир:** войну нужно объявить. Мир — белый, с сохранением занятого или с репарациями; враг соглашается, если ему это выгодно или он проигрывает.
- **Области** дают деньги, солдат или и то, и другое — по числу людей, которые в них живут (население из Natural Earth). Занятая чужая земля даёт половину и копит недовольство, пока через 12 ходов не станет своей; армия в области успокаивает народ, на 100% — восстание.
- **Столицы** отмечены звездой. Если столицу взяли, правительство переезжает в другую ключевую область (крупный центр или захваченную столицу). Страна капитулирует после 3 ходов без единой ключевой области.
- **Национальные цели:** у 10 крупных стран свои, у остальных общие. Каждая через несколько ходов даёт бонус навсегда.
- **Блоки:** компьютерные страны с похожей политикой объединяются и защищают друг друга. В блок своей идеологии можно вступить. Слишком сильного игрока ждёт коалиция.
- **Режимы карты:** политика, ресурсы, отношения, угрозы, недовольство.
- **Рейтинг стран:** общая сила, армия, флот, авиация, экономика, территория.
- **Решения, события, улучшения, политика партий** — как раньше, плюс экран итогов с графиком и достижениями.

## Разработка

```bash
npm install
npm run dev
```

- `npm run build` — сборка в `dist/`
- `npm run sim -- DE,FR,PL 60 8 normal` — компьютер играет партии за эти страны, для проверки баланса
- `npm run build:map` — пересобрать карту `src/data/europe.json`: страны из world-atlas (1:50m), области и побережья из провинций Natural Earth 1:10m (скачиваются один раз в `.cache/`)
- `npm run build:flags` — скопировать флаги в `public/flags`

Каждый пуш в `main` выкладывает игру на GitHub Pages.

Стек: TypeScript, Vite, d3-geo, d3-zoom, topojson. Карта — Natural Earth, флаги — [flag-icons](https://github.com/lipis/flag-icons) (MIT), иконки — [Lucide](https://lucide.dev).
